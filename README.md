# claude-workspace

A workspace for learning and building with Claude Code.

## wordfreq.py

Counts the most common words in a text file.

```bash
python3 wordfreq.py some-file.txt      # top 5
python3 wordfreq.py some-file.txt 10   # top 10
```

## chess/ — Chess Studio

A chess app for Windows and Android: play Stockfish or a friend online, with clocks, saved games, engine
review and training on your own mistakes. Live at https://rahulsg96-hub.github.io/Chess-Studio/ — see
[chess/README.md](chess/README.md).

## drone/ — Small quadcopter from scratch

An engineering design project: a sub-250 g, 3-inch quad with our own frame and flight-control
firmware, growing from manual flight to FPV, phone control and autonomy. See
[drone/README.md](drone/README.md).
